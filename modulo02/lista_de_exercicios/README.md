## Revisão geral

Depois de passar por todos os capítulos, feche o módulo misturando tudo:

| Lista | Foco | Arquivo |
| ----- | ---- | ------- |
| Revisão de Fundamentos | recapitula cada conceito | [revisao_fundamentos.md](revisao/revisao_fundamentos.md) |
| Desafios Integrados | problemas que combinam vários conceitos | [revisao/desafios_integrados.md](revisao/desafios_integrados.md) |

## Ordem sugerida

1. Para cada capítulo da trilha: faça a lista de **código** (fixação, completar, achar o bug, prever a saída, escrever do zero) e só então a lista **aplicada**.
2. Siga a ordem da tabela (variáveis → condicionais → laços → funções → arrays → objetos).
3. Feche com **Revisão de Fundamentos** e depois **Desafios Integrados**.

> Cada lista de código aumenta a dificuldade por etapas: **Parte 0** (exercícios de fixação), **Parte 1** (completar o código), **Parte 2** (achar o bug), **Parte 3** (prever a saída) e **Parte 4** (escrever do zero). Use apenas conceitos já vistos até o capítulo.

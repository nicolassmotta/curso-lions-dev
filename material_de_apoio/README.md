# Material de Apoio

Guias de consulta rápida para usar durante todo o curso. Não são listas de exercícios: abra quando precisar lembrar de um método, entender um erro ou testar uma API.

| Material | Para que serve | Use a partir do |
| -------- | -------------- | --------------- |
| [Guia de Erros Comuns](erros_comuns.md) | encontrar a mensagem de erro que apareceu e saber como resolver | Módulo 02 |
| [Cola: Métodos de Array, String e Número](cola_arrays_strings.md) | lembrar o que cada método faz e se ele altera o original | Módulo 02 |
| [Guia: Testando APIs no Postman](testando_apis.md) | montar requisições, usar variáveis e token, e criar o roteiro de testes | Módulo 07 |
| [Tabela de Status HTTP](status_http.md) | escolher o status certo de cada resposta da API | Módulo 07 |

# Módulo 11 — Lista de Exercícios

Este módulo transforma as APIs dos alunos em interfaces. A prática deve reforçar que frontend não é só visual: ele precisa enviar requests corretos, receber responses reais e lidar com sucesso/erro.

## Exercícios

| Exercício | Objetivo | Arquivo |
| --------- | -------- | ------- |
| Frontend com IA | Gerar uma tela de cadastro a partir de uma rota `POST` real do backend. | [frontend_com_ia.md](frontend_com_ia.md) |
| FlutterFlow consumindo API | Criar uma tela de listagem no FlutterFlow usando uma rota `GET` real. | [flutterflow_listagem_api.md](flutterflow_listagem_api.md) |

## Sequência sugerida

1. Escolher uma API já construída nos módulos 07 a 10.
2. Conferir se a API roda localmente ou está publicada no Render.
3. Testar a rota no Postman.
4. Criar a interface com IA ou FlutterFlow.
5. Testar no navegador a requisição real.
6. Registrar prompt usado, ajustes feitos e erros corrigidos.

## Critério comum de aceite

- A interface roda sem erro.
- A URL da API está correta.
- Os nomes dos campos batem com o backend.
- A tela mostra dados reais ou envia dados reais.
- O aluno consegue explicar qual rota foi chamada, qual body foi enviado e qual response voltou.
